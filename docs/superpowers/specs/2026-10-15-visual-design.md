# Language Cards: визуальный дизайн

Дата: 15 октября 2026. Статус: утверждено и реализовано. Визуальная система перенесена из интерактивного прототипа в рабочий React-интерфейс без изменения контрактов API и алгоритма интервальных повторений.

Прототип: [language-cards-concept.html](../../design/language-cards-concept.html). Файл открывается напрямую в браузере, не требует установки пакетов и работает без подключения к серверу. Тексты, числа и имена участников демонстрационные. Никакие данные в Telegram или базу не отправляются.

## 1. Задача и неизменные требования

Дать компании друзей приятный, быстрый интерфейс к собственным словам. Основной сценарий: открыть приложение → начать повторение → вспомнить перевод → открыть ответ → оценить. Второй сценарий: скопировать список из сообщения → проверить строки → добавить карточки.

Продуктовые требования берутся из [утверждённой спецификации](2026-10-14-language-cards-design.md). Новое оформление не меняет интервальный алгоритм, роли, формат импорта и контракт API.

- Общее содержимое группы; отдельные личные прогресс и расписание.
- Личные карточки смешиваются с общими в тренировке выбранной группы.
- Оба направления доступны в одной тренировке.
- На учебной карточке только вопрос и раскрываемый ответ. Направление, источник, автор и статистика не помещаются на карточку.
- Четыре оценки: «Не вспомнил», «С трудом», «Вспомнил», «Легко».
- Нет письменного ответа, напоминаний, таймеров, серии дней, дневной нормы, XP или рейтингов друзей.
- Добавление общих слов доступно только подтверждённым аккаунтам `1568151709` и `735056285`, состоящим в группе. Создатель группы сам по себе не получает это право, но может редактировать и удалять любые общие карточки своей группы.

Главное дизайнерское решение: спокойное приложение с выразительным главным действием. Цвет помогает найти нужное действие; контент остаётся главным. Сильные анимации, стекло на каждой поверхности и декоративные панели для обучения не нужны.

## 3. Направление «Forest / Matcha / Paper»

Характер: тёплый, взрослый, дружелюбный. Бумажный фон, глубокий зелёный, мягкий лаймовый акцент, чёткие слова. Большие радиусы дают ощущение лёгкости, а тонкие разделители удерживают словарь компактным.

Название продукта остаётся Language Cards. Фраза «Свои слова. Общий язык.» используется только на презентационном поле макета, не занимает место на главном экране Mini App. Шрифт с засечками применяется только на этом презентационном поле; в самом приложении — системный шрифт устройства с поддержкой кириллицы.

## 4. Экраны

### Главная

Заголовок «С возвращением.», выбор активного набора, цветная область «Вернём слова в память.» с числом наступивших заданий. Ниже — число новых заданий и пометка об обоих направлениях. Главное действие: «Начать повторение».

Числа обозначают задания, а не количество уникальных слов. У одной карточки два независимых направления. Никакого индикатора выполнения дневной нормы.

Ниже — источники набора: общие слова группы и личные слова пользователя. Небольшая подпись объясняет приватность прогресса. Кнопка «Добавить слова» доступна и без перехода в словарь.

Когда нет заданий: спокойное сообщение и переход к словам. Когда нет карточек: «Добавьте слова, чтобы начать» и ввод списка. При загрузке чисел — статические скелетоны без мерцающей анимации; при ошибке — понятное сообщение и повторная загрузка.

### Повторение

Отдельный экран без нижней навигации. «Закончить» возвращает на главную. В production связывается с Telegram BackButton; собственная кнопка остаётся доступной при отсутствии нативной.

В центре — крупная непрозрачная карточка. До раскрытия она содержит только вопрос. После нажатия или «Показать перевод» появляются исходная сторона и перевод, разделённые тонкой линией. Подсказки и оценки расположены снаружи.

Сетка оценок: верхний ряд «Не вспомнил» и «С трудом», нижний «Вспомнил» и «Легко». У каждой есть подпись, цвет и простой символ. Цвет не является единственным носителем смысла.

Визуально следующий ответ появляется только после подтверждения сохранения сервером. На время запроса кнопки недоступны. При ошибке открытая карточка остаётся, сообщение и «Повторить отправку» видимы над оценками. Повтор использует тот же ключ операции, как в существующей реализации.

В макете очередь локальная и демонстрационная: «Не вспомнил» добавляет задание в конец. Это демонстрация взаимодействия, не реализация FSRS и не обещание точного интервала.

### Словарь

Один список пар с поиском по обеим сторонам. Фильтры «Все», «Общие», «Личные» в виде компактных переключателей. Никаких больших плиток для каждого слова: две строки и тонкий разделитель дают просмотреть больше содержимого.

Небольшой значок группы либо замка показывает принадлежность. Нажатие открывает детали; при отсутствии права редактирования поля только для чтения. Личные слова редактирует владелец. Автор общих редактирует свои, создатель — любые общие. Удаление требует подтверждения с обеими сторонами и соответствующей областью действия.

Кнопка «+» открывает выбор «Вставить список» / «Добавить одну пару». Поиск без результатов предлагает изменить запрос. Пустой словарь ведёт к добавлению.

### Добавление списком и предпросмотр

Два шага: список → проверка. Для обычного пользователя место назначения «Только мне» показано статичной меткой. Издателю в группе доступен переключатель «Только мне» / «В группу» с названием назначения. Создатель группы без права публикации не видит общую цель.

Пример заполнен словами из сообщения пользователя. В нём специально оставлены повтор `Provision` и строка без разделителя, чтобы показать обработку реальных данных.

Корректная строка: пара и галочка. Повтор: текстовое объяснение, галочка по умолчанию снята. Ошибка: исходная строка, два поля исправления и объяснение. Кнопка сохранения содержит число выбранных пар и недоступна, пока выбранная строка некорректна.

Прототип показывает основной разбор. Production продолжает использовать существующий серверный парсер, лимиты 500 строк / 2 000 символов на сторону, предпросмотр и подтверждение, версии и идемпотентность. Код демонстрационного парсера не переносится в backend.

### Группа

Название, число участников, список имён и роль создателя. Нет рейтинга, чужих оценок, серий дней и точности ответов. Общий набор видят все, прогресс остаётся личным.

Приглашение создаёт создатель группы. Издателю доступно добавление общих слов. Эти полномочия независимы. Обычному участнику доступен выход с подтверждением, создателю — нет. Создать новую группу и выбрать личный набор можно через выбор набора.

Переключатель ролей на презентационном поле циклически показывает участника, издателя и создателя без права публикации. В настоящем приложении роль подтверждает сервер; такого переключателя нет.

В демонстрационных данных издатель считается автором показанных общих карточек. В рабочем приложении доступность редактирования определяется серверными `can_edit` / `can_delete`, а не одной ролью издателя.

### Завершение

«На сейчас всё.» и два действия: к словам, добавить слова. Без конфетти, обещаний идеального запоминания, длительности занятия и давления продолжить. Текст не обещает, что до завтра не будет новых наступивших заданий.

## 5. Доступность, поведение и адаптивность

- Макет переключается между ширинами 320, 390 и 480 px. На мобильном экране презентационная рамка ограничивается доступной шириной. В рабочем приложении нет имитации рамки телефона, status bar и заголовка Telegram: их рисует клиент Telegram.
- В production учитываются `safeAreaInset`, `contentSafeAreaInset`, `viewportStableHeight` и обновления layout. Два набора отступов не складываются без проверки существующей интеграции.
- Длинные фразы переносятся. Перевод не обрезается многоточием. При длинном содержимом карточки доступна прокрутка, оценки остаются достижимы.
- Клавиатура требуется только при поиске, добавлении и редактировании. Элементы формы не прячутся под ней.
- Раскрытие ответа — 150 мс. Переходы — до 200 мс. При `prefers-reduced-motion: reduce` движение отключено.
- Контраст обычного текста — не ниже 4.5:1, крупного — 3:1. Рамка необязательной декоративной поверхности может быть слабее; фокус, обязательные границы и интерактивные обозначения должны различаться. Основание: [WCAG 2.2, Contrast Minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html).
- Доступные имена у иконок, видимый фокус, доступность клавиатурой, `aria-live` для ответа и результатов, `role=alert` для ошибок. Листы действий удерживают фокус и закрываются Escape.
- Blur применяется только к навигации и фону листа действий. На слабых устройствах допустим непрозрачный вариант без изменения структуры.

## 7. Реализация по SDD

Этот документ и прототип стали согласованной спецификацией для реализации. Перенос выполнен по плану [2026-10-15-visual-design-implementation.md](../plans/2026-10-15-visual-design-implementation.md): сначала общие токены и примитивы, затем главная, повторение, словарь, импорт, группы и сквозная визуальная проверка.

Реализация использует существующие `App`, `StudyHome`, `ReviewPage`, `FlashCard`, `RatingControls`, `WordListPage`, `ImportPage`, `GroupPage`, `CardEditor` и Telegram bridge. Новая архитектура backend и дополнительный UI-фреймворк не добавлены.

Визуальные изменения проверяются скриншотами обеих тем, узкой шириной и длинными фразами. Функциональные тесты компонентов и Docker-backed E2E остаются частью обязательной регрессии. Публикация на production-сервер в этот этап не входит.

## 8. Проверка реализации

Проверено 15 октября 2026 в Chromium через Playwright и в изолированном Docker test-stack:

- 42 состояния рабочего React-интерфейса: 7 экранов × 3 ширины (320 / 390 / 480 px) × 2 темы. Горизонтального переполнения внутри приложения не обнаружено.
- 74 backend-теста и 52 frontend-теста прошли; production-сборка завершилась успешно.
- Раскрытие карточки, четыре оценки, ошибка сохранения и повторная отправка проверены в рабочем интерфейсе.
- Поиск по переводу, фильтр личных слов, предпросмотр шести строк, исключённый повтор и исправление ошибочной пары перед добавлением.
- Участник без общего импорта, издатель с общим импортом, создатель с приглашением и без права публикации; редактирование общей карточки создателем.
- Закрытие листа действий клавишей Escape и возврат фокуса, включая первую карточку словаря.
